# AI 101 maintenance

This is the public, static clinician education site at https://ai101.health.
There is no build step. Do not include local drafts or unrelated untracked files
in commits. Preserve the site's clinical caveats and cite primary sources.

For the **AI 101 Weekly Content Audit**, read
`docs/operations/weekly-audit.md` and `docs/audits/latest.json` before researching.
They supply the persistent backlog and completion criteria that are missing from
the original scheduled-task briefing. An empty GitHub issue list is not proof
that previous findings were resolved. Check prior calendar reports too.

Do not call a run complete just because research finished. Report research,
link-check, delivery, and publication status separately. A blocked source or a
403 on issue creation must remain visible in the report and notification.
